# 🛒 TrendKart – Full Stack E-Commerce App

TrendKart is a modern full-stack e-commerce web application built using the **MERN stack (MongoDB, Express, React, Node.js)** with a clean UI, authentication, cart, wishlist, and product search features.

---

## 🚀 Features

### 👤 User Features
- User registration & login (JWT authentication)
- Profile management (view user details)
- Logout with session cleanup

### 🛍️ Product Features
- Product listing with pagination (infinite scroll)
- Single product details page
- Product search functionality
- Responsive product cards

### ❤️ Wishlist
- Add/remove products from wishlist
- Real-time UI updates using React Query

### 🛒 Cart System
- Add to cart / remove from cart
- Prevent duplicate items
- View cart count in navbar

### 🔎 Search
- Search products using query params (`?search=keyword`)
- Dynamic filtering of products

---

## 🧑‍💻 Tech Stack

### Frontend
- React (Vite)
- TypeScript
- React Router DOM
- React Query (TanStack Query)
- Redux Toolkit
- Tailwind CSS
- Axios
- React Hook Form + Zod
- React Hot Toast

### Backend
- Node.js
- Express.js
- MongoDB + Mongoose
- JWT Authentication
- REST API
